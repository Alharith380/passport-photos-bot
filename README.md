# بوت تلجرام لصور جواز السفر

## ⚠️ مهم جداً بخصوص التوكن
التوكن الذي شاركته ظهر في محادثتنا هذه، وأي شخص يراه يستطيع التحكم الكامل ببوتك.
يُفضّل بشدة توليد توكن جديد الآن قبل الاستخدام الفعلي:
1. افتح محادثة **@BotFather** في تلجرام
2. أرسل `/mybots` → اختر بوتك → `API Token` → `Revoke current token`
3. انسخ التوكن الجديد واستخدمه بدلاً من القديم

## ماذا يفعل البوت؟
1. `/start` → يطلب من المستخدم إرسال صورة
2. المستخدم يرسل الصورة
3. البوت يسأل: 4 صور أم 8 صور؟
4. البوت يقوم تلقائياً بـ:
   - إزالة الخلفية (أي خلفية) بدقة عالية
   - وضع خلفية بيضاء نظيفة
   - تحسين طفيف للوضوح والتباين (بدون تغيير ملامح الشخص)
   - قص الصورة لتطابق نسبة صورة الجواز القياسية (35×45مم)
   - ترتيبها في شبكة (2×2 لعدد 4، أو 2×4 لعدد 8) على ورقة طباعة
     مقاس 4×6 إنش بدقة 300 DPI، مع خطوط قص رفيعة
   - إرسال الصورة النهائية جاهزة للطباعة

## التشغيل محلياً
```bash
python3 -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt

export BOT_TOKEN="ضع_التوكن_هنا"   # على ويندوز (PowerShell): $env:BOT_TOKEN="..."
python bot.py
```
أول تشغيل سيقوم بتحميل نموذج إزالة الخلفية (u2net_human_seg) تلقائياً، لذا يحتاج اتصال إنترنت في المرة الأولى فقط.

## التشغيل 24 ساعة مجاناً (بدون أن يبقى جهازك مفتوحاً)
البوت يحتاج خادماً يعمل باستمرار لأن تلجرام يعتمد هنا على "polling" (استعلام دوري)، خيارات مجانية شائعة:

- **Railway.app** – خطة مجانية محدودة، سهلة النشر من GitHub
- **Render.com** – Background Worker مجاني (مع سكون بعد فترة خمول على بعض الخطط)
- **Fly.io** – خطة مجانية صغيرة كافية لبوت بسيط
- **PythonAnywhere** – مناسب لسكربتات بسيطة (يحتاج ضبط لجعل العملية دائمة)

خطوات عامة للنشر (مثال Railway):
1. ارفع الملفات (`bot.py`, `requirements.txt`) إلى مستودع GitHub
2. أنشئ مشروعاً جديداً في Railway واربطه بالمستودع
3. أضف متغير بيئة باسم `BOT_TOKEN` بقيمة توكن بوتك
4. اجعل أمر التشغيل: `python bot.py`

## ملاحظات
- إن كانت الصورة المُرسلة ذات خلفية معقدة جداً أو إضاءة سيئة جداً، قد تحتاج جودة إزالة الخلفية لتحسين إضافي — يمكن تفعيل/تعديل معاملات `alpha_matting` في `remove_background_to_white()`.
- الأبعاد والمقاسات (35×45مم، ورقة 4×6 إنش) قابلة للتعديل من أعلى ملف `bot.py` (المتغيرات `PHOTO_ASPECT`, `SHEET_W_IN`, `SHEET_H_IN`).
- يمكن إرسال الصورة كـ"ملف/document" بدل صورة مضغوطة للحصول على أعلى جودة ممكنة (البوت يدعم الحالتين).
